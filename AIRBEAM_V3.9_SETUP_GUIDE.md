## 🎁 Two Ready-to-Share Packages

You have two ready-made options to share with friends, colleagues, or other PCs:

### Option A: The Full Installer (`AirBeam-v3.9-Setup.exe` — 34.2 MB) 🌟 Recommended
- **Best for:** Anyone who wants a standard Windows installation.
- **How to use:**
  1. Send `AirBeam-v3.9-Setup.exe` via Google Drive, Telegram, USB flash drive, or WhatsApp Web.
  2. The recipient simply double-clicks `AirBeam-v3.9-Setup.exe`.
  3. The Inno Setup wizard:
     - Installs AirBeam into `%LocalAppData%\Programs\AirBeam` (No admin prompt required!).
     - Creates a Desktop shortcut and Start Menu entry with the custom icon.
     - Adds Windows Firewall inbound allow rules automatically.
     - Adds a standard uninstaller in Windows Settings / Control Panel.
     - Launches AirBeam v3.9 immediately!

---

### Option B: The Portable ZIP (`AirBeam-v3.9-Portable.zip` — 43.0 MB)
- **Best for:** Running directly from a USB stick or for users who do not want to install anything on their system.
- **How to use:**
  1. Send `AirBeam-v3.9-Portable.zip`.
  2. The recipient extracts the ZIP file to any folder or USB drive.
  3. Double-click `AirBeam.exe` to run immediately!

---

## 🔒 Recipient System Requirements
- **OS:** Windows 10 or Windows 11 (64-bit).
- **Python:** **NONE!** Python is fully embedded and frozen inside the package. The recipient does not need Python, pip, or any coding knowledge.
- **Android APK Included:** The installer and portable pack bundle the Android receiver (`AirBeam-v2.7-Receiver.apk`) so Android devices can download it directly via the QR code or offline.
- **iOS Transfer Ready:** No app needed on iPhone/iPad; users simply scan the QR code to open the iOS Web Portal on port 8090.
